    Canada defaults¶

    Use these settings unless your local community lists different ones.

    Setting Canada default
    Radio preset USA/Canada (Recommended)
    Raw radio values 910.525 MHz / 62.5 kHz / SF7 / CR5
    Path hash mode 3-byte
    Command-line path setting set path.hash.mode 2

    Check local settings first

    Nearby devices need matching settings. A card marked Different local settings takes precedence over the Canada defaults after you confirm it with the listed community.
