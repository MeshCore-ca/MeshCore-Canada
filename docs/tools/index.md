# Network tools

Choose the tool that matches your task.

<div class="grid cards" markdown>

-   :material-tune-variant:{ .lg .middle } **Set up a repeater**

    ---

    Answer a few questions, one at a time, and get every command to paste, with what each one does.

    [:octicons-arrow-right-24: Set up a repeater](../config/index.md)

-   :material-book-open-variant:{ .lg .middle } **How repeaters work**

    ---

    What repeaters do, how scopes and regions decide where messages go, and what each setup command means.

    [:octicons-arrow-right-24: Read how repeaters work](../config/guide.md)

-   :material-map-search:{ .lg .middle } **Find your zone**

    ---

    Find a published MeshMapper zone or a placeholder zone. These boundaries are not radio coverage.

    [:octicons-arrow-right-24: Find my zone](../config/map.md)

-   :material-chart-timeline-variant:{ .lg .middle } **View the live network**

    ---

    View public observers, packets, nodes, and maps in the live network viewer.

    [:octicons-arrow-right-24: Open the live viewer (external)](https://live.meshcore.ca/){ target="_blank" rel="noopener" }

-   :material-access-point-network:{ .lg .middle } **Set up an observer**

    ---

    Choose an observer method, then check that its packets appear in the live viewer.

    [:octicons-arrow-right-24: Choose an observer method](../analyzer/intro.md)
