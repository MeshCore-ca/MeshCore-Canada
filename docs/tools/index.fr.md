# Outils réseau

Choisissez un outil selon votre tâche.

<div class="grid cards" markdown>

-   :material-tune-variant:{ .lg .middle } **Configurer un répéteur**

    ---

    Répondez à quelques questions, une à la fois, et obtenez toutes les commandes à coller, avec ce que fait chacune.

    [:octicons-arrow-right-24: Configurer un répéteur](../config/index.md)

-   :material-book-open-variant:{ .lg .middle } **Comprendre les répéteurs**

    ---

    Ce que font les répéteurs, comment les portées et les régions guident les messages, et ce que fait chaque commande.

    [:octicons-arrow-right-24: Lire comment fonctionnent les répéteurs](../config/guide.md)

-   :material-map-search:{ .lg .middle } **Trouver votre zone**

    ---

    Trouvez une zone publiée par MeshMapper ou une zone provisoire. Ces limites ne sont pas la couverture radio.

    [:octicons-arrow-right-24: Trouver ma zone](../config/map.md)

-   :material-chart-timeline-variant:{ .lg .middle } **Voir le réseau en direct**

    ---

    Consultez les observateurs, les paquets, les nœuds et les données
    cartographiques publics dans la visionneuse du réseau en direct.

    [:octicons-arrow-right-24: Ouvrir la visionneuse (site externe)](https://live.meshcore.ca/){ target="_blank" rel="noopener" }

-   :material-access-point-network:{ .lg .middle } **Configurer un observateur**

    ---

    Choisissez une méthode d’observation, puis confirmez que les paquets
    apparaissent dans la visionneuse du réseau.

    [:octicons-arrow-right-24: Choisir une méthode d’observation](../analyzer/intro.md)

</div>

Besoin d’aide? Consultez la page de
[dépannage des observateurs](../analyzer/troubleshooting.md) ou
[demandez à la communauté](../start/get-help.md).
